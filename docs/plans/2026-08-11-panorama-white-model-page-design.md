# 纯白模全景页面设计

**日期：** 2026-08-11  
**分支：** `codex/panorama-white-model-page`  
**状态：** 已确认，待实施

## 1. 背景与目标

现有 `index-3d.html` 同时承担户型浏览、模型操作、资源管理、材质控制和相机点位预览等职责。下一阶段需要提供一个面向全景浏览与点位管理的独立页面，使用户打开页面后直接进入白模全景视角，而不是先看到鸟瞰 3D 场景。

本期目标如下：

- 新增独立全景页面，不改变现有 3D 页面的入口和默认行为。
- 页面加载完成后直接进入一个合法的 `camera_list` 相机点位。
- 默认使用白模材质，并在全景状态显示吊顶和窗外景色。
- 支持通过小地图、点位列表和场景热点切换相机点位。
- 明确区分浏览模式与点位编辑模式，避免浏览过程中误改点位。
- 支持点位的新增、删除、重命名、位置和高度调整、初始点配置以及恢复。
- 通过可替换的数据仓库接口保存前端草稿，为后续 CAD Bridge 或服务端持久化留出扩展点。

## 2. 本期范围

### 2.1 包含内容

- 独立页面入口与专用应用控制器。
- 白模全景首屏与固定点位原地环视。
- 相机点位解析、选择和初始点回退策略。
- 小地图、点位列表、场景热点与视野外方向提示。
- 浏览模式和点位编辑模式。
- 点位位置、高度、名称、初始点以及新增、删除、恢复操作。
- 本地草稿持久化、异常恢复和版本隔离。
- 对现有 3D 页面和相关渲染能力的回归保护。

### 2.2 不包含内容

- 服务端离线光追任务提交、任务状态轮询和历史结果管理。
- AI 示意图、AI 风格选择、局部重绘及相关生图能力。
- CAD Plugin 的集成或修改。
- 现有 `index-3d.html` 的替换或默认交互变更。

## 3. 方案选择

采用“独立全景入口”方案：新增 `index-panorama.html` 和 `PanoramaApp`，复用现有场景加载、白模、相机点位、小地图、吊顶、窗外景色和全景控制模块。

未采用以下方案：

- 在 `index-3d.html` 中通过 URL 参数切换模式：改动较少，但会继续扩大 `App3D.js` 的职责并增加状态冲突。
- 先重构完整共享应用框架：长期结构更统一，但本期范围和回归风险过大。

独立入口可以保持现有稳定 3D 页面不变，同时让全景页面拥有清晰的产品边界。只在确有复用价值时抽取公共能力，避免为重构而重构。

## 4. 页面架构

### 4.1 页面入口

- `index-panorama.html`：纯全景页面 DOM、样式入口和无脚本兜底提示。
- `PanoramaApp`：负责页面启动、场景生命周期、模式切换和组件协调。
- `vite.config.3d.js`：增加全景页面构建入口，同时保留原有 3D 与 VR 入口。

### 4.2 复用能力

优先复用以下已有能力：

- `SceneManager`：场景、相机、渲染循环、白模材质和相机点位控制。
- `RoomRenderer` 及现有数据加载路径：户型、墙体、软装、门窗和其他模型渲染。
- `CameraPresetMap` 中的相机点位规范化与户型投影逻辑。
- 吊顶和全景模式窗外景色开关。
- 现有固定点位原地旋转控制及视场角处理。

如果现有组件包含 3D 页面专属 DOM 或行为，应先抽取无 UI 的纯函数或小型服务，再由两个页面分别组合，不能让全景页面反向依赖 `App3D`。

### 4.3 新增模块

- `PanoramaApp`：全景页面总控制器。
- `PanoramaPointStore`：原始数据、草稿数据和运行状态管理。
- `PanoramaPointRepository`：草稿持久化接口。
- `LocalPanoramaPointRepository`：基于浏览器本地存储的一期默认实现。
- `PanoramaPointList`：点位列表与点位操作界面。
- `PanoramaHotspots`：场景内热点和视野外方向提示。
- `PanoramaEditController`：点位编辑快照、移动校验、保存和取消。

## 5. 启动流程

1. 加载户型 JSON、白模结构、模型资源和 `camera_list`。
2. 解析并过滤非法相机点位，保留错误原因用于调试日志。
3. 按“方案 ID + 方案版本”加载本地草稿，并与当前原始点位合并。
4. 强制关闭材质还原，进入白模状态。
5. 选择首屏点位，优先级依次为：
   1. 草稿中配置的初始点位；
   2. 上次访问或编辑的合法点位；
   3. `camera_list` 中第一个合法点位。
6. 打开吊顶并启用仅限全景模式的窗外景色。
7. 将相机移动到选中点位，进入以相机自身为圆心的 360° 环视。
8. 同步小地图、点位列表、热点和顶部状态。

如果没有合法点位，页面不能回退到鸟瞰 3D，而应进入“创建第一个全景点位”的空状态。

## 6. 页面布局

页面沿用轻量 Liquid Glass 视觉风格，但删除与全景无关的 3D 编辑控件。

### 6.1 顶部栏

- 方案名称与版本。
- 当前房间和当前点位名称。
- 白模状态。
- “编辑点位”入口。
- 为后续离线渲染预留“生成全景图”位置，但本期不得接入虚假任务流程。

### 6.2 小地图

- 位于左上角，可折叠。
- 展示户型轮廓、房间和所有合法点位。
- 当前点使用蓝色，其他点使用黄色，存在未保存修改的点使用橙色状态提示。
- 点击标记后直接切换到对应全景点位，不经过鸟瞰视角。
- 编辑位置时实时更新点位标记。

### 6.3 点位列表

- 位于左侧并可折叠。
- 展示点位名称、所属房间、高度和状态。
- 支持选择、重命名、新增、删除、设为初始点和恢复。
- 删除操作必须二次确认；删除初始点后必须重新选择或自动回退到合法点位并明确提示。

### 6.4 场景热点

- 当前全景画面中显示其他点位热点。
- 点击热点切换点位。
- 点位不在当前视野内时显示方向提示和房间名称。
- 用户可以隐藏或显示热点与方向提示。

### 6.5 底部控制条

浏览模式显示：

- 上一个点、下一个点。
- 视角复位。
- 显示或隐藏热点。
- 进入或退出全屏。

编辑模式显示：

- 低速位置移动。
- 高度预设与微调。
- 保存、取消和退出编辑。

## 7. 交互与状态机

### 7.1 浏览模式

- 鼠标左键拖动只改变当前相机的朝向，相机位置保持不变。
- 滚轮只调整视场角，不执行场景平移。
- 小地图、点位列表和场景热点均可切换点位。
- 键盘移动键不得修改点位位置。
- 每个点位独立记录最近的朝向和视场角。

### 7.2 点位编辑模式

- 进入编辑时保存位置、高度、朝向和视场角快照。
- `WASD`、方向键或界面按钮执行低速连续平移。
- 移动结果实时同步到小地图和全景画面。
- 高度提供儿童、标准、加高三个预设，并允许小范围微调。
- 移动必须经过合法性校验：不能越出房间、穿墙或进入固定障碍。
- “保存”将修改写入草稿层和 Repository。
- “取消”完整恢复编辑前快照。
- 页面持续显示明确的编辑状态，不能让用户误以为仍处于浏览模式。

### 7.3 新增和恢复

- 无点位时，通过小地图选择合法房间位置创建首个点位。
- 有点位时，可从点位列表进入新增流程。
- 支持恢复当前点到原始 `camera_list` 状态。
- 支持恢复全部点，并清除本方案版本对应的本地草稿。

## 8. 数据模型与持久化

### 8.1 三层状态

- 原始层：只读保存 JSON 中规范化后的 `camera_list`。
- 草稿层：保存新增、移动、重命名、删除、高度和初始点配置。
- 运行层：保存当前点、各点浏览朝向、视场角、当前模式和临时编辑快照。

### 8.2 Repository 边界

`PanoramaPointRepository` 至少提供：

- `load(planId, version)`
- `save(planId, version, draft)`
- `clear(planId, version)`
- `backupCorrupted(planId, version, rawValue)`

一期使用 `LocalPanoramaPointRepository`。未来接 CAD C++ Bridge 或服务端时，替换 Repository 实现即可，页面组件和交互控制器不直接读写外部存储。

### 8.3 数据隔离

- 本地存储键必须包含方案标识和方案版本。
- 草稿需要包含 schema 版本。
- 当户型版本变化或 schema 不兼容时，不直接套用旧草稿。
- 损坏草稿先备份，再回退到原始点位数据。

## 9. 错误处理

- 户型 JSON 加载失败：显示错误说明和重试入口，不展示空白画布。
- `camera_list` 缺失或全部非法：进入首点创建引导。
- 配置的初始点非法：回退到第一个合法点并输出结构化调试日志。
- 部分模型资源失败：继续展示可用白模，并显示失败资源数量。
- 本地草稿损坏或版本不匹配：备份损坏值并回退到原始数据。
- 点位移动越界或穿墙：拒绝该次移动并显示轻量提示。
- WebGL 或全景能力不可用：显示兼容性说明和诊断信息。

## 10. 测试与验收

### 10.1 单元测试

- 相机点位规范化和非法数据过滤。
- 首屏点位优先级与回退策略。
- 原始层、草稿层和运行层合并规则。
- Repository 的版本隔离、损坏恢复和清理。
- 浏览/编辑状态转换、保存和取消快照。
- 移动合法性校验和越界拒绝。

### 10.2 组件与集成测试

- 小地图、列表和热点选择保持同步。
- 浏览模式的键盘输入不移动点位。
- 编辑模式位置与高度修改实时更新。
- 删除初始点和恢复操作符合约束。
- 无点位、JSON 失败、资源部分失败等异常状态可见且可恢复。
- 全景页面默认白模、吊顶开启、窗外景色只在全景状态出现。

### 10.3 回归测试

- 现有 `index-3d.html` 启动行为保持不变。
- 现有场景渲染、材质还原、相机点位、全景捕获和窗口测试继续通过。
- Vite 同时能够构建 3D、VR 和独立全景入口。

### 10.4 用户验收标准

- 打开全景页面后直接进入合法相机点位，不出现鸟瞰 3D 首屏。
- 首屏固定为白模，并正确显示吊顶。
- 左键拖动以相机自身为圆心完成 360° 环视。
- 小地图、点位列表和热点均能切换点位并保持状态同步。
- 浏览模式不会误改相机位置。
- 点位编辑支持位置、高度、名称、初始点、保存、取消和恢复。
- 刷新页面后，本方案版本对应的本地草稿仍然存在。
- 原有 3D 页面功能不受影响。

4. CAD Plugin 中的入口、数据桥接与持久化适配。
