# 140d02 Free-Window Rendering Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render every valid `140d02` free window as an atomic composite of parameterized `1401` straight-window and `140c` arc-window segments, matching the verified UE geometry, parameter, and placement behavior.

**Architecture:** Discovery continues to produce one normalized record per CAD source object. A pure adapter expands only valid `140d02` records after discovery and before template classification. Generated children reuse `ContentModelLoader`; arc math and placement live in focused pure helpers. `RoomRenderer` owns an identity staging group per original free window and commits it only when every child was placed, so the existing local fallback stays visible on any incomplete composite.

**Tech Stack:** JavaScript ES modules, Three.js 0.178, Node `node:test`, Vite 6, checked-in `Drawing2.json` and `template.json` fixtures.

- [ ] **Step 6: Implement the exact UE strip construction**

For `N` even points, split at `N/2`, reverse the back half, and for every `i` construct UE's call order:

```js
adjustSegment(front[i], front[i + 1], back[i + 1], back[i])
```

For a straight strip, reproduce `AdjustIrregularWindowData`:

1. Find the front midpoint.
2. Measure its perpendicular distance to the infinite outer line as `thickness`.
3. Normalize `V2 - V1` and choose its ±90° normal so `dot(normal, V4 - V1) >= 0`.
4. Set `middle14=(V1+V4)/2` and `middle23=(V2+V3)/2`.
5. Emit `[middle14-normal*thickness, middle23-normal*thickness, middle23+normal*thickness, middle14+normal*thickness]`, all bulges zero.

For an arc strip:

1. Describe `V1 -> V2` and `V3 -> V4` as bulge arcs.
2. Let `thickness=abs(inner.radius-outer.radius)` and choose `inner.radius ± thickness` whichever is closest to the original outer radius and remains positive.
3. Offset the inner arc concentrically to that radius.
4. Emit UE order `[V2, outerEnd, outerStart, V1]` with bulges `[0, -V1.bulge, 0, V1.bulge]`.

For straight children, set `basePoint` to adjusted point 0, `rotationDegrees` to the point-0→point-1 heading, `footprint` to all four world points, and `size` to `{x:edge01,y:edge12,z:height}`. Add semantic `长`, `宽`, `高度`, and `离地高度` values to a cloned `rawBlockInnerInfo`.

For arc children, preserve the adjusted four-point `cadPath`, a sampled display footprint, original height/ground facts, and neutral plan transforms. Copy safe parent identity fields exactly as specified in the approved design.
