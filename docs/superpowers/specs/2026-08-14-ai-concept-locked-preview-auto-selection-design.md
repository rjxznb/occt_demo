# AI 示意图预览锁定与自动全选设计

## 背景

AI 示意图页面当前使用 `SceneManager` 的固定点位相机。该相机模式默认接受鼠标拖拽旋转和滚轮缩放，但页面的 `ready` 与 `editing` 阶段只约束了键盘移动和按钮状态，导致普通预览时仍能改变视角。

页面同时保留了一套逐视角勾选机制，包括卡片上的“选择/已选”按钮、勾选标记和底部选择数量。新的产品规则是不再由用户手动挑选：点击生图时自动提交全部当前有效视角。

## 目标

- 普通预览阶段锁定固定点位相机，禁止鼠标拖拽旋转和滚轮缩放。
- 进入位置微调后开放拖拽旋转、滚轮缩放和现有位置移动。
- 保存或取消微调后立即重新锁定相机。
- 移除全部手动选择界面。
- 点击生图时自动提交全部当前可用视角。
- 不改变全景图和 3D 页面原有固定点位交互行为。

## 相机交互设计

### SceneManager 边界

`SceneManager` 增加一个显式的固定点位交互开关。该开关只决定固定点位模式下是否处理以下输入：

- 鼠标左键按下与拖拽旋转。
- 鼠标滚轮缩放。

固定点位模式本身、相机切换动画、程序化设置位置和朝向不受影响。开关默认开启，以保持全景图、3D 预览等现有调用方的行为。

关闭开关时需要取消尚未结束的拖拽状态，并移除拖拽中的光标样式，防止在微调过程中按下鼠标、随后退出微调时残留指针捕获状态。

### AI 页面状态映射

`AiConceptApp` 是 AI 页面交互状态的唯一协调者：

- 初始化并进入 `ready`：关闭固定点位交互。
- 切换缩略图或小地图点位：继续保持关闭，只允许程序化平滑切换。
- 进入 `editing`：开启固定点位交互。
- 保存微调：关闭固定点位交互，再恢复 `ready`。
- 取消微调：关闭固定点位交互，再恢复 `ready`。
- 错误、空状态、条件页面和销毁阶段：保持关闭。

键盘位置移动继续由现有 `PanoramaInputPolicy` 管理；本设计不改变其职责。

## 自动全选设计

### UI

从缩略图卡片中移除：

- “选择/已选”按钮。
- 右下角蓝色勾选标记。

从底部生图操作区移除“已选择 N 个视角”文字。保留以下操作：

- 点击缩略图切换当前预览视角。
- 微调。
- 删除或排除。
- 添加自定义视角。
- 生图。

### 提交数据

点击生图时不读取视角的历史 `selected` 字段，而是从当前 store 状态动态筛选所有可提交视角。可提交条件为：

- `valid !== false`。
- `status` 不是 `excluded`。
- `status` 不是 `disabled`。

自定义视角和自动生成视角遵守同一规则。已经删除的自定义视角不在 store 中，因此不会提交。筛选结果保持当前 store 中的稳定顺序。

为了兼容现有草稿数据，底层 `selected` 字段可以暂时保留，但 AI 示意图页面的 UI 与生图载荷不再依赖它。本次不做无关的数据迁移或 schema 升级。

## 异常与边界

- 如果没有任何可提交视角，生图操作保持不可用或返回失败，不进入空载荷流程。
- 非固定点位模式下调用交互开关只记录下一次固定点位模式应采用的权限，不切换相机模式。
- 关闭交互后，页面 UI 按钮仍可正常点击；只拦截画布上的相机拖拽和滚轮。
- 程序化切换视角不临时解锁用户输入。

## 测试

- `SceneManager` 单元测试：开关关闭时拖拽和滚轮不改变相机，开启时保持现有行为。
- `AiConceptApp` 测试：初始化锁定、进入微调解锁、保存和取消后重新锁定。
- Filmstrip 测试：卡片不再渲染选择按钮和勾选状态。
- 页面结构与样式测试：移除选择数量元素及相关选中样式。
- 生图载荷测试：包含全部有效且未排除/禁用的视角，不依赖 `selected` 字段。
- 浏览器验证：普通预览拖拽和滚轮无效；微调时生效；退出微调后再次锁定；生图操作区不再显示选择控件。
