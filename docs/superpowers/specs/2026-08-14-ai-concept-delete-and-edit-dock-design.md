# AI 示意图删除确认与底部微调条设计

## 目标

增强候选视角删除操作的安全提示与危险态反馈，并将微调控制条放置到页面底部居中，形成更清晰的编辑专注模式。

## 删除交互

- 每个候选视角缩略图上方的垃圾桶按钮使用现有 `data-action="delete"` 标识。
- 鼠标悬浮垃圾桶按钮时，背景变为柔和红色，图标颜色同步变红；键盘聚焦时提供相同的危险态反馈。
- 点击任意垃圾桶按钮后先显示浏览器确认框，提示是否删除对应视角。
- 用户取消确认时不改变视角、缩略图缓存或当前活动视角。
- 用户确认后：
  - 自动生成视角继续采用“排除”语义，可通过现有恢复能力重新显示；
  - 自定义视角继续采用永久删除当前草稿记录的语义。
- 确认逻辑位于自动视角与自定义视角分支之前，保证两类视角行为一致。

## 微调布局

- 任意已有视角或新增自定义视角进入 `editing` 后，微调控制条固定在页面底部居中。
- 桌面布局距底边 18px，使用水平居中定位，不依赖底部缩略图的位置。
- 窄屏布局左右各保留 12px、距底边 12px，允许内部控件换行。
- 微调期间继续隐藏候选缩略图、左右切换按钮和“下一步：生图条件”操作区。
- 小地图继续显示。
- 保存或取消后隐藏微调控制条，并恢复候选缩略图、左右切换按钮和生图条件操作区。

## 实现边界

- 删除确认由 `AiConceptApp.deleteView()` 统一处理。
- 危险态和微调条位置仅修改 `src/ai-concept/ai-concept.css`。
- 不新增自定义弹窗组件，不改变现有数据结构。
- 不修改 CAD Plugin。

## 测试标准

- 自动视角点击删除时调用确认框；取消后视角仍存在且状态不变。
- 自动视角确认后被排除且可以恢复。
- 自定义视角点击删除时调用确认框；取消后仍存在，确认后被删除。
- CSS 明确覆盖垃圾桶悬浮与键盘聚焦的红色危险态。
- 桌面微调条使用底部居中定位，窄屏使用 12px 底部安全间距。
- 微调期间生图条件操作区保持隐藏，保存或取消后恢复。
- 完整测试、生产构建和浏览器交互验证通过。
