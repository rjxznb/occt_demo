# 全景页标签隐藏与相机平滑切换设计

## 目标

独立全景页不再显示房间名称和面积的 Sprite 标签，同时让用户切换全景点位时从当前相机姿态平滑移动到目标点位，避免瞬间跳转。

## 范围

- 仅影响独立全景页，不改变原有 3D 预览页与 VR 页。
- 仅隐藏 `roomLabel` 房间名称/面积 Sprite，不隐藏全景热点、小地图标记或其他辅助对象。
- 平滑切换适用于小地图、点位列表、场景热点以及上一点位/下一点位按钮。
- 首次进入初始点位仍立即定位，不播放入场飞行动画。
- 编辑模式中的实时位置预览保持即时更新，不使用补间动画。

## 方案

### 房间标签

`PanoramaApp` 在 `RoomRenderer` 完成房间渲染后调用现有的 `setRoomLabelsVisible(false)`。隐藏职责继续由 `RoomRenderer` 维护，因此不遍历或修改场景中的其他 Sprite，也不会影响其他页面的默认标签状态。

### 相机过渡

在 `SceneManager` 中增加固定点位相机的平滑切换能力，并复用现有渲染循环逐帧推进：

1. 从当前固定点位相机姿态读取位置、偏航角、俯仰角和 FOV。
2. 将目标点位及其已保存视角作为过渡终点。
3. 使用 0.8 秒 ease-in-out 曲线插值位置、俯仰角和 FOV。
4. 偏航角沿最短角度路径插值，避免绕远旋转。
5. 每帧更新相机方向和投影矩阵。
6. 中途再次选择点位时，取消旧目标，并以当时的实时姿态为新动画起点。

`PanoramaApp` 的首次 `_enterPoint` 继续使用立即定位接口；用户主动切换点位时改用平滑接口。点位选择、视角草稿保存及 UI 状态仍由现有 Store 管理。

## 交互与异常处理

- 动画期间继续允许选择其他有效点位，新选择直接替换旧过渡。
- 无效点位或非有限坐标拒绝启动动画，并保持当前相机姿态。
- 固定点位模式尚未激活时，平滑接口退化为立即进入目标点位，确保调用安全。
- 用户开始拖动视角时取消尚未完成的自动过渡，避免动画与手势竞争。
- 销毁场景时清除过渡状态。

## 测试

- `PanoramaApp` 启动测试：房间渲染完成后调用 `setRoomLabelsVisible(false)`。
- `PanoramaApp` 交互测试：首次点位使用立即定位，主动切换使用平滑接口。
- `SceneManager` 测试：位置、最短偏航角、俯仰角与 FOV 按缓入缓出曲线推进并准确落到终点。
- `SceneManager` 测试：新目标可以中断旧动画，拖动视角会取消动画，无效输入不改变相机。
- 完整测试与生产构建，随后在真实浏览器中确认标签消失且多入口点位切换手感一致。

## 非目标

- 不调整热点样式、小地图布局或房间数据。
- 不引入 GSAP 等动画依赖。
- 不修改 CAD Plugin。
- 不改变离线全景图生成逻辑。
