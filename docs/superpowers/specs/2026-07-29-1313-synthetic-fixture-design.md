# 1313 L 型推拉门合成验证设计

## 目标

在没有真实 `1313` CAD 导出样本的情况下，使用一条仅在调试 URL 显式开启的合成记录，验证 OCCT 前端是否能按 UE 规则完成 `1313`（L 型推拉门）的资源识别、参数化请求、方向与位置计算。

## 边界

- 只修改 OCCT 前端源码、测试和文档。
- 不修改 `cad_plugin`，不部署 CAD 缓存。
- 不修改真实 `public/data/Drawing2.json`。
- 普通 `index-3d.html` 行为保持不变；仅 `?fixture=1313` 注入测试对象。
- 资源仍走现有统一内容模型链路：`TypeId -> template.json ResId -> 资源详情 -> 参数化模型`。

## UE 依据

`D:\view3d\BIMRunTime\Source\BIMRunTime\BuildHome\Private\Designer\BIMScene.cpp` 对 `1313` 有独立放置规则：

1. 模型局部人工包围盒使用 `(0, Size.Y, 0)` 到 `(Size.X, 0, Size.Z)`。
2. CAD 旋转角再减去 90°。
3. 以 CAD 几何的世界包围盒底面中心对齐上述模型局部包围盒底面中心。

模板 `public/data/template.json` 中 `1313` 映射到资源 `2412393`，资源详情表明它是参数化模型。模型根参数包含 `左宽`、`右宽`、`高度`、`左墙厚`、`右墙厚`。

## 设计

### 参数解析

将 `1313` 纳入拐角构件参数适配。根据 CAD 的 L 形轮廓、`BlockInnerInfo` 和点序解析左右边，并提交：

- `左宽`
- `右宽`
- `高度`
- `左墙厚`
- `右墙厚`

该逻辑复用已经由 `1407` 验证过的左右边/绕序解析，但不复用 `1407` 专属的窗体尺寸修正。

### 放置解析

为 `1313` 增加单独的 placement adapter：

- 最终旋转 = CAD 俯视旋转 - 90°；
- 局部对齐点 = `(Size.X / 2, Size.Y / 2, 0)`；
- 世界目标点 = CAD L 形轮廓的包围盒底面中心；
- 模型原点 = 世界目标点 - 最终旋转后的局部对齐向量；
- CAD 水平/垂直翻转继续沿用统一模型变换链路。

### 合成 fixture

增加一个纯数据的调试 overlay：

- 仅当查询参数 `fixture=1313` 时，克隆原始 drawing 并向 `door_list` 追加一条合成 L 形门记录；
- 不修改输入对象，避免污染后续加载；
- 合成对象包含 `TypeId`、`BasePoint`、`Points`、`Size`、高度、墙厚、旋转和翻转等 CAD 常用字段；
- 合成对象放在客厅轮廓的真实直角点 `(-1498.686324, -5448.045438)`，1200 mm 与 1500 mm 两翼分别沿向东、向北的连续墙段展开；
- fixture 只接入 `App3D`，不影响 VR 与生产/CAD 默认入口。

## 验证标准

1. 普通 URL 不出现合成门。
2. `?fixture=1313#debug` 能解析到 `ResId=2412393` 并走参数化请求。
3. 控制台无 ContentLoader 加载失败。
4. 模型竖直，L 形两翼尺寸合理。
5. 模型局部拐角与合成 CAD 轮廓对齐，方向符合 UE 的 `-90°` 规则。
6. 现有全量测试与 `build:3d` 通过。
